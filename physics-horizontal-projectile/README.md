# ملزمة الفيزياء — حل التقييم الأسبوعي: المقذوف الأفقي (HTML)

نسخة HTML مطابقة لتصميم الـ PDF الأصلي «حل التقييم الأسبوعي - الفيزياء - المقذوف الأفقي»:
نفس الألوان المستخرجة من الملف (الأصفر `#FFD43B`، البورجوندي `#7C1747`، الفيروزي `#0E7C86`)
ونفس الخطوط الأصلية (Lalezar للعناوين، Readex Pro للنصوص والقوانين، Alexandria).

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | **الملف النهائي الجاهز للاستخدام** — ملف واحد مستقل (اللوجو مضمّن داخله)، افتحه بأي متصفح |
| `template.html` | المصدر القابل للتعديل (نفس المحتوى لكن الرسومات واللوجو على هيئة رموز `%%DIAGRAM:..%%`) |
| `build.py` | سكربت البناء: يولّد رسومات المقذوفات كـ SVG ويدمج اللوجو ثم ينتج `index.html` |
| `assets/logo.jpg` | اللوجو الأصلي المستخرج من الـ PDF |

## الاستخدام

- **العرض:** افتح `index.html` في المتصفح. الصفحات بمقاس A4 حقيقي (210×297mm)
  وتتصغّر تلقائيًا على شاشات الموبايل.
- **الطباعة / حفظ PDF:** زر «طباعة / حفظ PDF» أعلى الصفحة — اختر مقاس A4،
  الهوامش «لا شيء»، فعّل «رسومات الخلفية Background graphics»، والمقياس 100%.
  النتيجة: ١٧ صفحة مطابقة للأصل.
- **وضع الاختبار (إضافة للشاشة فقط):** زر في الشريط العلوي يخفي الإجابات وخطوات الحل؛
  الطالب يضغط على الاختيار فيتلوّن صح/غلط، وزر «عرض الحل» يكشف حل كل سؤال.
  الوضع الافتراضي والطباعة يعرضان التصميم بالحلول كما في الأصل، وشريط الأدوات لا يظهر في الطباعة.

## التعديل وإعادة البناء

عدّل النصوص أو التنسيق في `template.html` ثم شغّل:

```bash
python3 build.py
```

(أو عدّل `index.html` مباشرة لو تعديلك نصي بسيط.)

> الخطوط تُحمَّل من Google Fonts، فالعرض الكامل يحتاج إنترنت؛
> بدونه تظهر خطوط النظام الاحتياطية وتظل الصفحة قابلة للقراءة والطباعة.
